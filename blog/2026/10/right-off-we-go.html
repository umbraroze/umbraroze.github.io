    Right, off we go!

    I’m still probably not going to publicise this blog all that much, but I now at least have a) a Jekyll theme that looks kinda good and b) a much better way of publishing this content (using the raw branch deploy instead of relying on the old GitHub Pages build process).

    Anyhow, here’s some of the stuff I’ve been working on:

    • Conman’s Dictionary: Basically, I’ve been having a 10 year odyssey of Not Getting Anything Done with this project. I decided to abandon the C# version that was going forward glacially slowly, decided that the Rust version was just hopeless on the outset – and went back to Java.

      So I’m definitely looking forward to learning what has been happening in Java land since Java SE 6. …I hear things have been happening. A lot of things.

      In particular, this will be a great exercise in learning OpenJFX and modern stuff like Gradle.

    • PhotoFlow: My photo importer is stable-ish, but there are things that need work to make the whole thing clearer.

      Also, I need to start working on some of the cool new tools, and really start getting in the habit of filling the bug tracker with all of the random ideas.

    • LankkuTraktori: Decided to write some Commodore 64 disk extractor things. Just learning the ropes of the Python construct library, I guess. This isn’t working much yet, at all, but I’ve got a feeling I’ll be putting some heavy time on this one.

    Yeah, I know, this really is a random update out of the blue, and I’m not really addressing this to anyone at all, but I need to journal some of the stuff I’m doing for my own sake.
